# COMPland

La tierra de la emulación y las compilaciones. Web estática en inglés con botón para español, desplegada en Vercel.

## Cómo editar

Todo el contenido (análisis, PC de pruebas, enlace de Telegram, noticias, compilaciones, calendario) está en **content.js**. Cada texto lleva su versión en inglés (`en`) y en español (`es`). Edita ese archivo en GitHub, guarda y Vercel publica solo.

- `index.html`: diseño y estilos
- `app.js`: lógica (mapa, filtros, idioma)
- `brand/`: logos en SVG
